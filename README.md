# 스피드브리딩 시설 통합 관리

예전에는 `index.html` 파일 하나에 모든 코드(약 9,500줄)가 들어 있었어요.
지금은 **내용은 그대로 두고** 기능별 파일로 나눠 담았어요. 화면과 동작은 예전과 똑같아요.

## 파일 안내

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 (메뉴, 창, 입력 칸의 틀) |
| `style.css` | 디자인 (색, 크기, 배치) |
| `js/core.js` | 기본 설정 · 공통 도구: 데이터베이스 연결, 한국 시간 날짜 계산, 방·베드 구조, 관리자 모드, 데이터 불러오기 |
| `js/overview.js` | **[종합현황]** 시설 배치도, 방 상세, 환경 설정, 방 상태 |
| `js/lines-form.js` | **[계통작성]** 입력 양식, 엑셀 업로드, 분기별 계획에서 불러오기 |
| `js/lines.js` | **[계통작성]** 화면: 방·자리 선택, 베드 맵, 계통 카드, 재료 |
| `js/harvest.js` | **[계통작성]** 수확 완료 목록, 세대진전, 다시 심기 |
| `js/history.js` | 세대 이력 검색, 세대 이력 창 |
| `js/tasks.js` | **[작업계획]** 작업 달력, 작업 요청·기록 |
| `js/survey.js` | **[수요조사]** 신청 양식, 응답 결과 |
| `js/plan.js` | **[분기별 계획]** 계획 작성·저장, 일정표 |
| `js/plan-adjust.js` | **[분기별 계획]** 수요조사 요청 반영: 겹침 확인, 옮기기, 복사·붙여넣기, 개체수 나누기 |
| `js/tour.js` | 사용법 투어 (투어 내용은 이 파일 위쪽 `TOUR_STEPS`에서 고쳐요) |
| `js/main.js` | 메뉴 전환과 앱 시작 |
| `js/tour-shots.js` | 사용법 투어의 예시 스크린샷 그림 데이터 (직접 고치지 말고, 바꾸려면 다시 만들어 달라고 하세요) |

## 이제부터는 이 파일들을 고쳐요

예전처럼 `index.html` 하나를 통째로 고쳐서 올리면 안 돼요. 그러면 나눈 파일과 내용이 어긋나요.
고칠 기능이 들어 있는 파일만 고쳐서 올리세요.

## 지켜야 할 규칙 두 가지

1. **파일 불러오는 순서를 바꾸지 마세요.**
   `index.html` 맨 아래의 `<script src=...>` 줄 순서가 중요해요. `core.js`가 맨 처음이어야 하고, 지금 순서를 그대로 지켜 주세요.

2. **파일을 고치면 버전 숫자를 바꿔 주세요.**
   `index.html`에서 `?v=20261102` 같은 숫자가 버전이에요. 고친 파일의 숫자를 오늘 날짜처럼 새 값으로 바꾸면, 사용자 브라우저가 예전 파일 대신 새 파일을 받아요.
   AI에게 고쳐달라고 할 때 "고친 파일의 버전 숫자도 올려줘"라고 덧붙이면 돼요.

## AI에게 수정을 부탁하는 법

고칠 기능이 들어 있는 파일만 알려주세요. 예를 들면 이렇게요.

> "survey.js에서 수요조사 양식에 '연락처' 칸을 추가해줘. 다른 파일은 건드리지 말고, 바꾼 부분을 알려줘."

그러면 AI가 상관없는 기능을 실수로 바꿀 일이 줄어요.

## 올리는 법 (GitHub Desktop)

1. 고친 파일을 이 폴더에 덮어써요.
2. GitHub Desktop에서 바뀐 줄(빨강·초록)을 확인해요.
3. 아래 칸에 바꾼 내용을 한 줄로 적고 **Commit** → **Push**를 눌러요.
